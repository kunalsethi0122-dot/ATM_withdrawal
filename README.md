# ATM Withdrawal System

## Project Description
The ATM Withdrawal System is a simple Python-based project that simulates basic ATM operations. It allows users to access ATM services using a PIN and perform basic banking transactions.

## Features
1. PIN Authentication
2. Check Account Balance
3. Withdraw Money
4. Deposit Money
5. Handle Invalid Inputs
6. Handle Insufficient Balance
7. Display Transaction Messages

## Concepts Used
- Python Programming
- Conditional Statements (if-else)
- User Input
- Exception Handling (try, except, finally)
- Variables

## Exception Handling
This project uses:
- **try:** To execute code that may generate errors.
- **except:** To handle errors without crashing the program.
- **finally:** To execute the final statement when the session ends.

## How to Run the Project

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python atm.py
```
